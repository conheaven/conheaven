## 👋 关于我

> *"不辞辛劳，尽善尽美"*

我关注 **AI 安全** 与 **安全研究** 的交叉领域，希望模型不只是更聪明，也能更可靠、更值得信任。

- 🔬 **研究方向**：视觉语言模型（VLM）安全、意图感知（Intent Awareness）、多模态对齐
- 📚 **论文追踪**：NDSS、USENIX Security、CCS、IEEE S&P 等安全顶会
- 📰 **信息工具**：热点聚合、舆情分析、自动化推送

## 🔭 最近在做

- 📄 复现 **SIA**（ArXiv 2025）：通过意图感知提升视觉语言模型的安全性
- 🤖 自动抓取安全顶会论文，支持定时任务与增量更新
- 🧭 探索热点聚合 + AI 分析的信息工具
